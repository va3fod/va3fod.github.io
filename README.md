# Val’s Apps · VA3FOD

This is the public landing page for Val’s apps, at [https://va3fod.github.io/](https://va3fod.github.io/).

## Apps

- [Science & Math Adventure](https://va3fod.github.io/Science-Math-Adventure/) — a free science and math learning game for kids. It works offline, and there are no ads.
- [The Boolean Machine Shop](https://va3fod.github.io/Boolean-Machine-Shop/) — build real-life water and lever machines that think in TRUE and FALSE. A free logic-gates game for kids that works offline, with no ads.
- [Șeptică](https://va3fod.github.io/Septica/) — the classic Romanian card game, for 2 or 4 players versus the computer.
- [Purrfect Landing Solitaire](https://va3fod.github.io/Purrfect-Landing-Solitaire/) — Klondike solitaire with a cat theme and an aviation theme. It has winnable deals, a daily challenge and high scores, and it works offline.
- [RC Flight Log by Val](https://rc-flight-log-by-val-925911568211.us-west1.run.app) — a free app for logging RC flights. It works offline with no account, and your data stays on your device.

The live page is always `index.html` in this repository. GitHub Pages is served from the `main` branch root.
